## SQL 实现

```sql
SELECT
    dept,
    name,
    salary,
    rn  AS ranking
FROM (
    SELECT
        dept,
        name,
        salary,
        RANK() OVER (
            PARTITION BY dept
            ORDER BY salary DESC
        ) AS rn
    FROM employees
) t
WHERE rn <= 3;
```

---

### 逐层解读

| 层级 | 作用 |
|------|------|
| **内层子查询** | 用窗口函数 `RANK()` 在**每个部门内**（`PARTITION BY dept`）按薪资**降序**（`ORDER BY salary DESC`）生成排名 `rn` |
| **外层查询** | 过滤 `rn <= 3`，只保留每个部门排名前 3 的行，并输出 `dept, name, salary, ranking` |

---

### 关于三种排名函数的选择

| 函数 | 并列处理 | 示例（薪资 100,100,90,80） | 适用场景 |
|------|---------|---------------------------|---------|
| `RANK()` | 并列同名，**跳号** | 1, 1, 3, 4 | 允许并列，"前 3 名"可能 >3 人 |
| `DENSE_RANK()` | 并列同名，**不跳号** | 1, 1, 2, 3 | 严格取前 3 个薪资档位 |
| `ROW_NUMBER()` | **不并列**，强制唯一 | 1, 2, 3, 4 | 严格取 3 个人（即使薪资相同） |

> 上面用的是 `RANK()`（最常用）。若业务要求"严格 3 人"，把 `RANK()` 换成 `ROW_NUMBER()` 即可；若要求"前 3 个不同薪资"，换成 `DENSE_RANK()`。

---

### 示例输出

假设数据：

| dept | name | salary |
|------|------|--------|
| 研发 | 张三 | 30000 |
| 研发 | 李四 | 28000 |
| 研发 | 王五 | 28000 |
| 研发 | 赵六 | 25000 |
| 市场 | 钱七 | 22000 |
| 市场 | 孙八 | 20000 |

执行结果（`RANK()`）：

| dept | name | salary | ranking |
|------|------|--------|---------|
| 研发 | 张三 | 30000 | 1 |
| 研发 | 李四 | 28000 | 2 |
| 研发 | 王五 | 28000 | 2 |
| 市场 | 钱七 | 22000 | 1 |
| 市场 | 孙八 | 20000 | 2 |

> 注意：研发部李四、王五并列第 2，`RANK()` 下第 3 名被"跳过"，赵六（25000）排名为 3 仍会被选出；若改用 `ROW_NUMBER()`，则赵六排名为 4，将被排除。
